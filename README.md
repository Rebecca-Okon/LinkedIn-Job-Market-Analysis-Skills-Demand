Project 14: LinkedIn Job Market Analysis – Skills Demand

Dataset: LinkedIn Job Postings (Web Scraping/API)
Introduction:
Job seekers need insights into in-demand skills. This project analyzes LinkedIn job postings to
identify trending skills (Python, SQL, AWS).

Key Questions to Answer:
1. Which tech skills are most frequently listed in job postings?
2. How has demand for AI/ML roles changed over time?
3. Which industries (IT, Finance, Healthcare) offer the highest salaries?
   
Tasks to Perform:
● Scrape/clean job postings (BeautifulSoup/Selenium).
● Perform text mining (NLP) on job descriptions.
● Visualize skill trends (word clouds, bar charts).

Deliverables:
● Skills demand report.
● Interactive skill trend dashboard.
